# ZhaoBuyan — 嵌入式学习作品集

从 STM32F429 裸机起步 → FreeRTOS → 嵌入式 Linux 驱动 / BSP 方向的学习记录。

## 开发环境

| 项目     | 内容                                                       |
| -------- | ---------------------------------------------------------- |
| 开发板   | STM32F429IGT6（Cortex-M4F @180MHz，1MB Flash，256KB SRAM） |
| 工具链   | STM32CubeMX + Keil MDK5 + ST-Link                          |
| 调试串口 | USART1 @115200-8-N-1                                       |

## 目录结构

```
stm32-to-linux/
└── STM32F429/
    ├── LED_Key_Control/   # RGB 三色灯 + 按键：寄存器级 GPIO、EXTI 中断
    ├── UART_Test/         # 串口：阻塞 → 中断 → DMA + 空闲中断（不定长收发）
    ├── TIM_Test/          # 定时器：TIM6 定时中断（1s）+ 串口验证
    ├── light0.0.1/        # 早期测试工程（保留记录）
    └── _archive/          # 旧备份（不提交）
```

## 阶段 2：STM32F429 裸机 + FreeRTOS（主线）

| 内容               | 说明                                              | 状态 |
| ------------------ | ------------------------------------------------- | ---- |
| GPIO 寄存器操作    | 直接写 `MODER` / `BSRR`，HAL 只是包装             | ✅   |
| 非阻塞定时         | `HAL_GetTick()` 时间戳 + 状态机，替代 `HAL_Delay` | ✅   |
| 按键扫描与消抖     | 轮询 + 软件消抖（不阻塞主循环）                   | ✅   |
| EXTI 外部中断      | 中断驱动的按键，对比轮询                          | ✅   |
| TIM 定时中断       | PSC/ARR 算周期 + 中断回调                         | ✅   |
| PWM 输出           | 呼吸灯 / 调光                                     | ⬜   |
| UART 中断/DMA 收发 | 阻塞 → 中断 → DMA+空闲中断                        | ✅   |
| UART 环形缓冲      | 配合不定长数据，实现队列式收发                    | ⬜   |
| SPI                | 读写外部器件（如 FLASH / 屏幕）                   | ⬜   |
| I2C                | 读写传感器（如 EEPROM / 陀螺仪）                  | ⬜   |
| ADC / DAC          | 采样、DMA 搬运                                    | ⬜   |
| FreeRTOS           | 任务 / 队列 / 信号量 / 互斥量 / 优先级            | ⬜   |
| 综合项目           | 2~3 个完整多任务项目（含文档）                    | ⬜   |
