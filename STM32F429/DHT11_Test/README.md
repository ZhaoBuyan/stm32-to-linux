# DHT11_Test — 温湿度采集 + 阈值报警

## 功能

- 每秒读取一次 DHT11 的**温度 / 湿度**，通过串口实时上传
- 温度 **> 30℃** 时：**报警 LED 快速闪烁** + 串口打印警告
- 读取失败时打印提示信息，**程序不会卡死**

## 硬件连接

| 器件             | 连接                                        |
| ---------------- | ------------------------------------------- |
| **DHT11 数据线** | → **PB0**（单总线，需上拉电阻）             |
| **报警 LED**     | → **PH10**（板载 RGB 红灯，**低电平点亮**） |
| 调试串口         | USART1 @ **115200-8-N-1**                   |
| 供电             | 3.3V（**不能接 5V**）                       |

## 实现要点

| 技术点           | 说明                                                    |
| ---------------- | ------------------------------------------------------- |
| **单总线协议**   | 自己实现：起始信号 → 等响应 → 收 40 bit → 校验          |
| **微秒级时序**   | 用 **DWT 周期计数器**（`HAL_Delay` 最小 1ms，根本不够） |
| **引脚动态切换** | 运行中改写 `MODER` 寄存器，实现 输出 ↔ 输入 切换        |
| **非阻塞闪烁**   | 报警用"时间戳 + 秒退"，不占用主循环                     |
| **模块化**       | 驱动独立成 `dht11.c` / `dht11.h`，应用层只看两个函数    |

**接口（dht11.h）：**

```c
void    DWT_Init(void);                          /* 使能微秒计时 */
uint8_t DHT_Read(uint8_t *temp, uint8_t *humi);  /* 0=成功 1=无响应 2=校验失败 */
```

## DHT11 协议速记

```
【起始】主机拉低 18ms → 释放
【响应】从机：80us 低 + 80us 高
【数据】40 bit，每个 bit = 50us 低 + 高电平
          高电平 26us  → 该 bit = 0
          高电平 70us  → 该 bit = 1
【内容】湿度整数 + 湿度小数 + 温度整数 + 温度小数 + 校验和
        （校验和 = 前 4 字节之和的低 8 位）
```

## 关键点

- **两种时间尺度**：应用层用**毫秒**（`HAL_GetTick`），协议层用**微秒**（DWT）
- **DWT 使能三行**是"标准咒语"，照抄即可；`1us = 180 个 CPU 周期`
- `IDR` 读电平（输入的 `ODR`）；`MODER` 切方向；`BSRR` 拉高拉低
- 校验用"求和取低 8 位"（`(uint8_t)` 强转截断）
- **非阻塞**：能不用 `HAL_Delay` 就不用（报警闪烁靠时间戳）
- 模块化：**上层的代码不关心下层的实现**
