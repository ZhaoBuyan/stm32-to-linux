## 六组用例测什么

| 用例 | 抓什么错                                |
| ---- | --------------------------------------- |
| 1    | 初始化不是空的 / 空的时候乱写 `*b`      |
| 2    | 最基础的存取                            |
| 3    | 容量算错（多存或少存一格）              |
| 4    | 满了之后不会"解封"（`Count` 状态错）    |
| 5    | ⭐ **跨数组末尾回绕**（最容易错的一处） |
| 6    | `head/tail` 绕了 3 圈之后仍然正确       |

## 这个练习为什么值得做

它同时是三件事的入口：

|                             |                                                    |
| --------------------------- | -------------------------------------------------- |
| **阶段 2 的 ⬜**            | 串口那条线就差"环形缓冲 + 不定长接收"              |
| **并发与同步的入门**        | 中断写、主循环读，最小规模的并发                   |
| ⭐ **Linux 内核的 `kfifo`** | 内核里同一个东西，同样的"单生产者单消费者无锁"思路 |
| 顺带练 C                    | 指针、数组回绕、`volatile`、`&` 代替 `%`           |

## 上板子的时候

串口中断接收时这么用：

```c
/* 中断里：只管塞，不处理 */
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart == &huart1) {
        RB_Put(rx_byte);                        /* 满了就丢，返回值可以记个计数 */
        HAL_UART_Receive_IT(&huart1, &rx_byte, 1);
    }
}

/* 主循环里：慢慢取、慢慢解析 */
while (RB_Get(&ch) == 0) {
    parse(ch);
}
```

**中断只做一件事，主循环做全部处理** —— 这就是"快进快出"。
