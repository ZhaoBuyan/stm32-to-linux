# TIM_Test — 定时器 TIM6 定时中断

## 功能

- TIM6 每 **1 秒**产生一次中断，中断里累加计数器
- 主循环把计数和间隔通过串口打印出来

## 硬件 / 配置

| 项目       | 值                                       |
| ---------- | ---------------------------------------- |
| 时钟源     | **HSE**（外部晶振 25MHz）→ SYSCLK 180MHz |
| 定时器时钟 | **APB1 Timer clocks = 90MHz**            |
| TIM6       | **PSC = 8999**，**ARR = 9999**           |
| 调试串口   | USART1 @ 115200-8-N-1                    |

**验算：**

```
(8999+1) × (9999+1) ÷ 90,000,000 = 9000 × 10000 / 90MHz = 1 秒
```

## 现象

串口每秒打印一行：

```
tick=1  interval=1000
tick=2  interval=1000
...
```

## 遇到的问题 & 解决

1. **时钟源误用了 HSI**（内部 RC）
    - 新建工程时**漏了 `RCC → HSE = Crystal/Ceramic Resonator`**，代码里是 `RCC_PLLSOURCE_HSI`
    - HSI 精度差（±1%~4%，随温度漂移）→ UART 波特率、定时都不准
    - 解决：改成 HSE
    - **教训：新建工程必查 RCC → HSE**

2. **改了时钟源，忘了改 PLL 参数**
    - HSE = 25MHz 时，原来的 `PLLM = 8` → VCO 输入 = 3.125MHz，**超出 1~2MHz 范围**
    - 解决：`PLLM = 25` / `PLLN = 360` / `PLLP = 2` → VCO 输入 1MHz、VCO 输出 360MHz、SYSCLK 180MHz

3. **CubeMX 里改配置 ≠ 代码生效**
    - 必须点 **`GENERATE CODE`** 才会重新生成 `.c` 文件

## 关键点

- 定时器三要素：**CNT**（计数器）、**PSC**（预分频）、**ARR**（自动重装载）
- **定时周期 = (PSC+1) × (ARR+1) ÷ 定时器时钟频率**
- ⭐ **APB 预分频 ≠ 1 时，定时器时钟 = APB 时钟 × 2**
  （所以 APB1 = 45MHz，但 TIM6 时钟 = 90MHz）
- PSC / ARR 都是 **16 位**，最大 65535
- 中断回调里**只 `tick++`**（快进快出），**串口打印放在主循环**
- 用 `HAL_GetTick()` 测两次中断的间隔，验证精度（≈1000ms，抖动 ±1ms）
- **硬件定时器 vs 软件时间戳**：硬件中断精度由硬件保证，不受主循环影响
