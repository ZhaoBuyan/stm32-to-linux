# 硬件引脚表 与 测试记录

## 一、硬件引脚表

### 1.1 输入输出

| 外设或信号 | 实际引脚 | 配置或有效电平 |
| --- | --- | --- |
| KEY1 | PA0 | 输入、内部下拉；**按下为高电平** |
| KEY2 | PC13 | 输入、内部下拉；**按下为高电平** |
| RGB LED 红 | PH10 | 推挽输出、无上下拉；共阳极，**低电平点亮** |
| RGB LED 绿 | PH11 | 同上 |
| RGB LED 蓝 | PH12 | 同上 |
| 串口 TX / RX | PA9 / PA10 | USART1 复用功能；115200-8-N-1 |
| 调试接口 | PA13 / PA14 | SWD（未占用、未重映射）|

### 1.2 传感器

| 器件 | 总线 | 引脚 | 地址 | 说明 |
| --- | --- | --- | --- | --- |
| **MPU6050**（板载加速度计）| **软件 I2C** | **PB6 = SCL，PB7 = SDA** | 7 位 `0x68`（8 位 `0xD0`）| 量程 ±2g / ±250°/s，200 Hz 内部采样 |
| **GT911**（屏的触摸 IC）| **软件 I2C** | **PH4 = SCL，PH5 = SDA** | 8 位 `0xBA`（7 位 `0x5D`）| 复位 PI8，中断 PD13 |

> ⚠️ **MPU6050 和 GT911 不在同一条 I2C 总线上**，所以给 MPU6050 单独写了一套软件 I2C，
> 不复用野火触摸的那套（它的引脚是 PH4/PH5）。

### 1.3 显示与显存

| 项 | 参数 |
| --- | --- |
| 屏幕 | 7 寸 RGB 电容屏，**800 × 480** |
| 像素格式 | **RGB565**（每像素 2 字节）|
| LTDC 时钟 | PLLSAI：`420 MHz / R=7 / DivR=4` = **15 MHz** |
| 行场参数 | HBP 46、VBP 23、HSW 1、VSW 1、HFP 22、VFP 22 |
| 实际刷新率 | 15e6 / ((800+46+1+22) × (480+23+1+22)) ≈ **32.8 Hz** |
| 显存 | SDRAM bank2，基址 **0xD0000000**，FMC 16 位宽，CAS 2 |
| 绘制方式 | **CPU 直接写显存**（不用 DMA2D，避免和 LTDC 抢总线）|

### 1.4 时基

| 定时器 | 中断周期 | 配置 | 用途 |
| --- | --- | --- | --- |
| TIM6 | **1 ms** | PSC = 8999，ARR = 9 | 主循环节拍、按键采样、用时统计 |

## 三、验收演示步骤

| 步骤 | 操作 | 预期现象 |
| --- | --- | --- |
| 1 | 上电，放平不动 | 屏幕亮，显示 `LEVEL 1/12 READY`，白灯，串口打印校准值 |
| 2 | 点 `START` 或按 KEY1 | 小球出现在左下，状态变 RUNNING，蓝灯 |
| 3 | 前后左右倾斜开发板 | 小球跟随倾斜滚动，速度箭头指向运动方向 |
| 4 | 放平板子 | 小球逐渐停下，箭头消失 |
| 5 | 把球推进右上绿色目标区 | 弹出 `LEVEL CLEAR` 横幅，绿灯 |
| 6 | 点 `NEXT` 或按 KEY1 | 进入第 2 关 |
| 7 | 一路推进到第 7 关 | 出现红色危险区 |
| 8 | 把球推进红区 | 弹出 `TRY AGAIN`，红灯 |
| 9 | 点 `RETRY` 或按 KEY1 | 本关重来 |
| 10 | 进行中点 `PAUSE` | 球定住，黄灯，出现 `RESUME` / `RESTART` |

**可选的加分演示**：在电脑上用 `EmbeddedScreenPreview` 打开本工程，不烧录直接看到同一画面。
