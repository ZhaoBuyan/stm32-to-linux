## 一、硬件引脚表

| 外设或信号 | 实际引脚 | 配置或有效电平 |
| --- | --- | --- |
| LED | **PH10** | 推挽输出、无上下拉、低速。板载 RGB 红灯，**共阳极 → 低电平点亮**（`ODR` 该位 = 0 为亮） |
| KEY1 | **PA0** | 输入、内部下拉。**按下 = 高电平**（✅ 已实测确认） |
| KEY2 | **PC13** | 输入、内部下拉。**按下 = 高电平**（✅ 已实测确认） |
| 串口 TX / RX | **PA9 / PA10** | USART1，复用推挽 / 浮空输入。115200、8 位、无校验、1 位停止位。**已使能 USART1 全局中断（NVIC）** |
| DHT11 数据引脚 | **PB0** | 运行中动态改写 `MODER` 在 输出 ↔ 输入 之间切换；内部上拉（建议外接 4.7 kΩ~10 kΩ 上拉）。3.3 V 供电，**不可接 5 V** |
| 基础定时器 | **TIM6** | PSC = 8999，ARR = 99 → 90 MHz ÷ 9000 ÷ 100 = **100 Hz，中断周期 10 ms**。中断处理只做 `g_tick10++` |

### ⚠️ 考场需再确认

1. **DHT11 引脚**：本工程用 **PB0**（已在 PB0 接线实测通过）。若考场接口说明指定的是板上 DHT11 座（如 PC6/PC7），需按原理图改引脚，同时改 `dht11.c` 里的 `DHT_PIN_NUM`。
2. **LED**：使用板载 RGB 红灯 PH10。若考场要求外接 LED，需确认接法与有效电平。

## 三、接收超时验收操作

| 测试过程 | 预期结果 | 实际结果 |
| --- | --- | --- |
| 发送 `@LED=`，**关闭自动追加换行**，等待超过 2 秒 | 返回一次 `ERR,TIMEOUT`，LED 保持原状态 | ✅ 通过 |
| 超时后发送 `@LED=1` + 换行 | LED 点亮，返回 `OK,LED=1` | ✅ 通过 |
| 超时后继续等待超过 2 秒 | 不重复返回超时错误 | ✅ 通过 |
| 不发送任何数据，等待超过 2 秒 | 不出现 `ERR,TIMEOUT` | ✅ 通过 |
| **附加**：发 `@` → 等 1 秒 → 发 `L` → 再等 1.5 秒 | 报 `ERR,TIMEOUT`（计时从 `@` 起算，后续字符不重新计时） | ✅ 通过 |
