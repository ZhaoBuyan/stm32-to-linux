# 硬件引脚表 与 测试记录

## 一、硬件引脚表

| 外设或信号 | 实际引脚 | 配置或有效电平 |
| --- | --- | --- |
| LED | PH10 | 推挽输出、无上下拉；板载 RGB 红灯，共阳极，**低电平点亮** |
| KEY1 | PA0 | 输入、内部下拉；**按下为高电平** |
| KEY2 | PC13 | 输入、内部下拉；**按下为高电平** |
| 串口 TX / RX | PA9 / PA10 | USART1 复用功能；115200-8-N-1 |
| DHT11 数据引脚 | PB0 | 运行中动态切换 输出/输入；内部上拉 |
| 基础定时器 | TIM6 | 中断周期：**10 ms**（PSC = 8999，ARR = 99） |

## 二、测试记录

| 序号 | 测试内容 | 实际结果 |
| --- | --- | --- |
| 1 | 复位后 LED 关闭 | 通过 |
| 2 | KEY1 开灯、KEY2 关灯，连续操作 10 次 | 通过 |
| 3 | 按键开灯后查询返回 `LED=1` | 通过 |
| 4 | 串口关灯后查询返回 `LED=0` | 通过 |
| 5 | 环境查询返回真实温湿度或传感器错误 | 通过 |
| 6 | 非法参数与带多余字符的命令报错，LED 不变 | 通过 |
| 7 | 收到 `@` 后 2 秒内未收到结束符，返回一次超时错误 | 通过 |
| 8 | 超时后的完整命令正常执行 | 通过 |
| 9 | 超时后继续等待超过 2 秒，不重复报错 | 通过 |
| 10 | 空闲超过 2 秒，无接收超时错误 | 通过 |

## 三、接收超时验收操作

| 测试过程 | 预期结果 | 实际结果 |
| --- | --- | --- |
| 发送 `@LED=`，关闭自动追加换行，等待超过 2 秒 | 返回一次 `ERR,TIMEOUT`，LED 保持原状态 | 通过 |
| 超时后发送 `@LED=1` + 换行 | LED 点亮，返回 `OK,LED=1` | 通过 |
| 超时后继续等待超过 2 秒 | 不重复返回超时错误 | 通过 |
| 不发送数据，等待超过 2 秒 | 不出现 `ERR,TIMEOUT` | 通过 |

## 四、提高任务测试

| 任务 | 测试过程 | 实际结果 |
| --- | --- | --- |
| 协议异常恢复 | 发送超过 32 字节的命令；发送 `@ABC@LED=0` | 返回一次 `ERR,LENGTH`；`@ABC@LED=0` 返回 `OK,LED=0` |
| 传感器故障恢复 | 拔掉 DHT11 数据线后 `@ENV?`；插回后再查 | 返回 `ERR,SENSOR`；插回后恢复正常 |
| LED 闪烁控制 | `@BLINK=1` 观察；闪烁中连续 `@LED?`；`@BLINK=0` | 每 500 ms 翻转；查询值随实际亮灭变化；停止并关灯 |
| 周期数据上报 | `@REPORT=1` 等待；`@REPORT=0` | 每 2 秒上报 `ENV,T=..,H=..`；关闭后停止 |
